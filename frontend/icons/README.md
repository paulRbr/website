Store all svg icons you want to easily use with the `Icon` ruby component here.

All icons are from https://remixicon.com/ and keep the remix icon file names for easier maintenance.

Some icons come from [Vuesax icons](https://www.figma.com/community/file/1037171936958147285/vuesax-icons) and are named accordingly.

💡 Tip: go on the `/icons` url to view all available icons at a glance and easily retrieve code snippets.
